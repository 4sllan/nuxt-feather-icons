**Nuxt Feather Icons** is an optimized, native icon solution for the Nuxt ecosystem. It transforms all Feather icons into Vue render functions (`h()`), ensuring the smallest possible bundle size and maximum performance.

## ✨ Key Features

This module is designed to be "invisible" in your workflow, providing a fluid development experience with extremely lightweight production results:

- **Zero-Runtime Compiler:** Pre-compiled icons that don't weigh down the browser execution.
- **Smart Tree-Shaking:** Only the icons you actually use are included in your final build.
- **Auto-imported Components:** Use `<HomeIcon />` or `<UserIcon />` anywhere without manual imports.
- **Dynamic Resolver:** Specialized `useFeatherIcon()` composable for icons coming from databases or dynamic menus.
- **SSR & Hydration Ready:** Ultra-fast server-side rendering with perfect hydration on the client.
- **Flexible Customization:** Native support for size, stroke-width, and seamless **Tailwind CSS** integration.
- **First-class TypeScript:** Full typing for all properties and icon names.

## Why Nuxt Feather Icons?

Unlike libraries that load a massive SVG sprite or rely on generic external icon libraries, this module treats each icon as an individual, highly-optimized Vue component.

If you need a clean, minimalist interface focused on performance (Core Web Vitals), this is the ideal choice for your Nuxt project.
