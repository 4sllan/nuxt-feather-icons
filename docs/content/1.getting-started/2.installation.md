## Quick Start

The fastest way to get started is by using the `nuxi` CLI to install the module and automatically register it in your `nuxt.config.ts`:

```bash [Terminal]
npx nuxi@latest module add nuxt-feather-icons
```

Alternatively, you can manually install the dependency using your preferred package manager:

```bash [Terminal]
pnpm add nuxt-feather-icons
# or
npm install nuxt-feather-icons
```

Then, manually register the module in your `nuxt.config.ts`:

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-feather-icons'
  ]
})
```

## Configuration
Nuxt Feather Icons works out of the box with zero configuration. However, you can customize the behavior (such as adding a component prefix) in your `nuxt.config.ts`:

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    'nuxt-feather-icons'
  ],

  // Optional: Module configuration
  nuxtFeatherIcons: {
    /** * Add a prefix to all icon components. 
     * Example: 'F' will turn <HomeIcon /> into <FHomeIcon />
     */
    prefix: '' 
  }
})
```

## Why PNPM?
Since this module relies on high-performance tree-shaking and a virtual mapping strategy, 
we recommend using pnpm for faster dependency resolution and more efficient disk usage in your Nuxt projects.

That's it! You are ready to start using high-performance icons in your Nuxt app ✨
