The **Nuxt Feather Icons** module is designed to be zero-config by default. However, you can fine-tune its behavior to
match your project's naming conventions and requirements.

## Module Options

All configurations are handled under the `nuxtFeatherIcons` key in your `nuxt.config.ts`.

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-feather-icons'],

    nuxtFeatherIcons: {
        // Your configuration here
        prefix: 'F'
    }
})
```

## Options Reference

| Property | Type   | Default | Description                                      |
|----------|--------|---------|--------------------------------------------------|
| prefix   | string | ''      | A string to prepend to all icon component names. |

## The `prefix` Option

Setting a prefix is useful if you want to avoid naming conflicts with other component libraries or if you prefer a
specific naming convention.

- Default (`''`): `<HomeIcon />`
- With `prefix: 'F'` : `<FHomeIcon />`
- With `prefix: 'Icon'` : `<IconHomeIcon />`

## Global Properties

Each icon component supports the following Vue Props. These can be passed directly to the component or through the

`useFeatherIcon` composable.

| Prop         | Type             | Default | Description                                                                              |
|--------------|------------------|---------|------------------------------------------------------------------------------------------|
| size         | string \| number | 24      | The width and height of the SVG. Supports numeric pixels or CSS units (2rem, 1.5em, 2x). |
| stroke-width | number           | 2       | The thickness of the icon's paths.                                                       |
| class        | string           | ''      | CSS classes passed to the SVG element. Works perfectly with Tailwind CSS.                |

## TypeScript Support

The module provides full TypeScript definitions out of the box. You don't need to do anything to get autocompletion for:

1. Component Names: Your IDE will suggest all available icons (considering your custom prefix).

2. Props: Strict typing for `size` and `stroke-width`.

3. Composable: The `useFeatherIcon` function returns a Vue component or `null` when the icon name is empty or invalid.

## Type Example

If you need to type an icon name in your own interfaces:

```typescript
// Example of typing a menu item
interface MenuItem {
    title: string
    // Use a string that matches an icon name
    icon: string
}
```

## Performance Summary

- Architecture: Virtual Icon Mapping.
- Bundle Impact: ~0.5KB (base runtime) + only used SVGs.
- SSR Support: 100% compatible.
- Tree-shaking: Automatic via Vite/Rollup.
