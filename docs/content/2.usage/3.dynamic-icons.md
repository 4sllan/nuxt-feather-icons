One of the most powerful features of **Nuxt Feather Icons** is the ability to render icons dynamically without losing the benefits of tree-shaking. This is ideal for sidebars, menus, and dashboard data.

## The `useFeatherIcon` Composable

While you can use `<component :is="..." />` with strings in Vue, doing so often forces the bundler to include the entire icon library. The `useFeatherIcon` helper uses a **virtual mapping strategy** to resolve only the icons you actually request.

### Basic Implementation

Pass the **PascalCase** name of the icon as a string to the composable:

```vue
<script setup lang="ts">
// No imports needed! The composable is auto-imported.
const iconName = 'UserIcon'
const DynamicIcon = useFeatherIcon(iconName)
</script>

<template>
  <component :is="DynamicIcon" size="24" class="text-green-500" />
</template>

```

## Rendering Lists & Menus
This is the most common use case for dynamic icons. You can map your navigation arrays directly to icon components.

```vue
<script setup lang="ts">
const menuItems = [
  { label: 'Home', slug: 'HomeIcon', path: '/' },
  { label: 'Cloud', slug: 'CloudIcon', path: '/cloud' },
  { label: 'Security', slug: 'LockIcon', path: '/security' }
]
</script>

<template>
  <ul>
    <li v-for="item in menuItems" :key="item.label">
      <component 
        :is="useFeatherIcon(item.slug)" 
        size="18" 
        class="mr-2" 
      />
      {{ item.label }}
    </li>
  </ul>
</template>
```

## Handling Custom Prefixes
If you have configured a custom prefix in your `nuxt.config.ts, you must include it when calling the composable.

```typescript [nuxt.config.ts]
// nuxt.config.ts
export default defineNuxtConfig({
  nuxtFeatherIcons: {
    prefix: 'F'
  }
})

// In your component
const icon = useFeatherIcon('FHomeIcon')
```

## Pro Tip: Dynamic Prefixes
If your data only provides the raw name (e.g., `Home`), you can easily append your prefix:

```typescript
const getIcon = (name: string) => useFeatherIcon(`F${name}Icon`)
```

## Benefits of this approach
- Performance: Even when using a string, Vite knows exactly which SVG to bundle.
- SSR Safety: Fully compatible with Server-Side Rendering and hydration.
- Zero Overhead: No reactive overhead for resolving the icon component.
