Nuxt Feather Icons provides two primary ways to render icons: **Static Components** (best for most cases) and the **Dynamic Composable** (best for lists, menus, or database-driven content).

All 280+ Feather icons are automatically registered as components. You can use them anywhere in your Vue templates
without importing anything.

---
Simply use the **PascalCase** name of the icon:

```vue

<template>
  <div class="flex gap-4">
    <HomeIcon/>

    <UsersIcon size="2x" class="text-blue-500"/>

    <SettingsIcon :stroke-width="1.5"/>
  </div>
</template>
```

## Dynamic Icons

If you need to render icons dynamically (for example, iterating through a navigation array), use the `useFeatherIcon`
composable.
This method is highly optimized for tree-shaking and runtime performance.

```vue

<script setup lang="ts">
  const navItems = [
    {label: 'Home', icon: 'HomeIcon'},
    {label: 'Analytics', icon: 'BarChartIcon'},
    {label: 'Settings', icon: 'SettingsIcon'}
  ]
</script>

<template>
  <nav>
    <div v-for="item in navItems" :key="item.label">
      <component :is="useFeatherIcon(item.icon)" size="20"/>
      <span>{{ item.label }}</span>
    </div>
  </nav>
</template>
```

## Available Props

Every icon component (and the dynamic resolver) accepts the following properties:

| Prop         | Type            | Default | Description                                  |
|--------------|-----------------|---------|----------------------------------------------|
| size         | `string,number` | 24      |                                              |
| stroke-width | number          | 2       | Thickness of the icon lines.                 |
| class        | string          | ''      | Standard Vue class binding for CSS/Tailwind. |

## Styling with Tailwind CSS
Since these icons are rendered as clean SVGs, you can use any Tailwind utility classes to style them, including transitions, colors, and animations:

```html
<HeartIcon 
  class="text-red-400 hover:text-red-600 transition-colors duration-300 cursor-pointer" 
/>
```
