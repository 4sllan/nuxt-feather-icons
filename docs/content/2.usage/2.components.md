Every icon in the Feather set is available as a first-class Vue component. Since they are pre-compiled into render
functions, they are extremely fast and support all standard Vue features.

## Naming Convention

By default, all icons follow the **PascalCase** naming convention based on their original Feather name, followed by the
`Icon` suffix.

- `home` → `<HomeIcon />`
- `user-plus` → `<UserPlusIcon />`
- `bar-chart-2` → `<BarChart2Icon />`

> [!TIP]
> If you defined a `prefix` in your `nuxt.config.ts`, remember to prepend it. For example, with `prefix: 'F'`,
`<HomeIcon />` becomes `<FHomeIcon />`.

## Component Props

All icon components share a unified set of props for easy styling:

| Prop           | Type               | Default | Description                                                                |
|----------------|--------------------|---------|----------------------------------------------------------------------------|
| `size`         | `string \| number` | `24`    | Sets width and height. Supports `px`, `em`, `rem`, or shorthand like `2x`. |
| `stroke-width` | `number`           | `2`     | Defines the thickness of the icon lines.                                   |
| `class`        | `string`           | `''`    | Custom CSS classes.                                                        |

### Examples

```vue

<SearchIcon size="16" :stroke-width="1"/>

<AlertTriangleIcon size="48" :stroke-width="3" class="text-yellow-500"/>

```

## Attributes Inheritance

Since these are functional components, any extra attributes you pass (like `aria-label`, `id`, or `@click` listeners)
will be automatically forwarded to the underlying `<svg> element.

```vue 

<template>
  <button @click="download">
    <DownloadIcon aria-hidden="false" aria-label="Download File"/>
    Download
  </button>
</template>
```

## Global vs. Local

Because of Nuxt's auto-import feature, you do not need to import icons manually.
They are available globally in your `.vue` files, and Vite will automatically handle the tree-shaking to ensure only the
used icons end up in your production bundle.
